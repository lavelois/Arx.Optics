# 波矢

$$\mathbf{k} = (k_{x},k_{y},k_{z})$$

波矢 (wave vector) 是个矢量, 它包含:
- 空间相位的变化速率
- 波的相位传播方向

### 波数

波矢的模长称为 **波数**

$$\boxed{|\mathbf{k}| = k}$$

### 真空中的波矢

$$ k_{0} = \frac{\omega}{c} = \frac{2\pi}{\lambda_{0}}$$

### 非真空介质中的波矢

$$k = \texttip{n}{折射率}k_{0} = \frac{2\pi n}{\lambda_{0}}$$

波长:

$$\lambda = \frac{\lambda_{0}}{n}$$
